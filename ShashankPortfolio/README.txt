SHASHANK - PERSONAL PORTFOLIO WEBSITE

This project uses only HTML, CSS and JavaScript. It does not require React, Node.js, npm or a build step.

FILES
- index.html          Main website page
- style.css           Website styling and responsive layout
- script.js           Mobile navigation and current year
- profile-photo.jpeg  Your supplied profile photograph

OPEN THE WEBSITE
1. Extract this ZIP file.
2. Open the extracted ShashankPortfolio folder.
3. Double-click index.html to open it in your browser.
   Alternatively, open the folder in VS Code and use Live Server if installed.

EDITING
Open index.html in VS Code to edit your bio, college details, interests, activities, achievements and contact information.

HOSTING
These files can be uploaded directly to a GitHub repository. For GitHub Pages, choose the repository's Settings > Pages and publish from the main branch and root folder.

NOTE
The achievements section says achievements and certificates will be added later because no specific awards or certificates were supplied.
